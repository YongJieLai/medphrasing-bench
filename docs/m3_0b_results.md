# M3-0b 归因结果：Δ 小，是假病人钝，还是考题太简单

> 派单 §7.13。本单只做归因，不改任何已有数据、不重建病例池。
> 结论先行：**两个假设叠加，但主因是 H_a（考题太简单/真值集太小），H_b（假病人钝）在采样层面被排除**。
> 关键证据：①模拟器在 info_units【采样】层面对 open/closed 有 +5.88 条/对话的响应，但【实际披露】被 10 条真值集天花板压平成 −0.25 条；②去掉候选列表后诊断 Δ 完全归零（+0.000，McNemar 9:9 p=1.0），绝对准确率从 0.733 掉到 0.524（候选列表贡献 21pp 假正确）。

---

## 1. 检查 1：披露量回抽（只读，零成本）

回抽器 = 纯词法（事实内容词覆盖 + 医学同义词 + 数字归一），**非 LLM，与医生(qwen-flash)/诊断(deepseek-chat)/判别(qwen-plus) 均不同源**。回抽对象是 `results.jsonl` 里患者【实际发言】文本，**未用计划披露量（`iu` 字段）**。

### 必报五个数

| # | 指标 | A-12 | B-12 | A-6 | B-6 |
|---|---|---|---|---|---|
| 1 | 每段对话总条数 均值 / 中位数 / IQR | 10.64 / 10 / [10,12] | 10.89 / 11 / [10,12] | 10.69 / 11 / [10,12] | 10.59 / 11 / [10,12] |
| 2 | A−B 差点估计 + bootstrap 95% CI | 12轮 **−0.25** [−0.48, −0.01] | | 6轮 **+0.10** [−0.15, +0.34] | |
| 3 | 每轮均值曲线 | turn0 2.74 / turn2 5.51 / turn4 1.02 → 4-5 轮说完全部事实 | | | |
| 4 | 零披露轮次占比 | **68.4%** | **59.3%** | 37.1% | 24.1% |
| 5 | 回抽一致率 | 抽 40 段（20 段实质披露 + 20 段含 r0/agree），**约 95%**，1 处位置词漏配误判 | | | |

### 判据落档：字面落 H_b 档，但辅助证据推翻

按 §7.13 判据，A−B = −0.25 < 1.0 → 字面落 **H_b**。但这里有一个**判据缺陷**必须上报：

- **计划采样值（`iu` 字段之和，非回抽）**：A-12 均值 31.77 条 vs B-12 25.90 条，**A−B = +5.88 条**。
- 这证明**模拟器在 info_units 采样层面对 open/closed 有强响应**（开放组"想"披露 31.77 条 vs 封闭组 25.90 条）——假病人**不钝**。
- 回抽 −0.25 是**真值集天花板（10 条）压平**的结果：12 轮里 4-5 轮就把 10 条事实说完了，后面 68% 的轮次是"没有了/附和"（零披露）。

> 判据缺陷：§7.13 用"实际披露量差"判 H_b/H_a，但真值集只有 10 条时，"实际披露量差"被天花板压平，**必然** < 1.0，会把 H_a 误判成 H_b。这正是 §7.2.12 主控预警的"用被压过的数解释被压过的结果"。

## 2. 检查 2：开放式诊断（只重跑诊断，约 1/20 成本）

105 例 12 轮对话（A、B 各一份）重放给 deepseek-chat，prompt 只给主诉 + 对话记录，**无候选列表、无 differentials、无任何疾病名/器官名/科室名**。评分用 qwen-plus 语义等价判等（与诊断 deepseek-chat 不同源），抽 20 条人工核对。

| 指标 | 值 |
|---|---|
| acc_A（开放式） | **0.524** |
| acc_B（封闭式） | **0.524** |
| Δ = A − B | **+0.000** |
| 95% CI | [−0.076, +0.076]（宽 15.2pp，落"功效不足"档） |
| McNemar | 9:9，p=1.0000 |
| 分层 | easy A0.51/B0.60、medium A0.57/B0.54、hard A0.49/B0.43 |
| **绝对准确率** | **0.524 > 0.4，12 轮 73% 仍可引用**，但说明候选列表贡献 ~21pp 假正确 |

**解读**：若 H_a 的"候选列表饱和"是 Δ 消失的元凶，去掉候选后 Δ 应变大（露出真实信息差）。实际 Δ 反而从 +3.8pp 归零——说明**不是候选列表造成的**，而是**两组实际披露的事实无差异**（检查 1 已证：真值集天花板压平）。

## 3. 合并结论：H_a 主因 + H_b 次因，两者叠加

| 假设 | 证据 | 判定 |
|---|---|---|
| **H_a** 因变量饱和 / 真值集太小 | 采样 A−B=+5.88 但回抽 −0.25；零披露 68%；4-5 轮说完全部事实；去候选 Δ=0 | **主因，成立** |
| **H_b** 患者侧幅度被压 | M2d 已证幅度仅真实 46–51%（采样 +5.88 本身可能也是被压缩后的值） | **次因，无法单独测出** |

**一句话理由**：模拟器在采样层面确实对 open/closed 有响应（+5.88），不钝；但 10 条真值集远小于 12 轮容量，实际披露被天花板压平，两组说出的事实几乎一样，诊断（无论有没有候选）自然无差异。

**修复方向（按优先级）**：
1. **先修真值集**（H_a）：真值集 10-15 → 30+ 条**判别性**事实，让 12 轮（甚至 6 轮）问不完。对应主控 §7.2.12 认领的设计错误，也是 M3-1（P2 病例池 15-20 轮、15-25 事实）的方向。
2. **再校准模拟器幅度**（H_b）：扩大真值集后，重新测采样幅度是否仍卡在 46–51%，若是则回修 M2d 的幅度压缩机制。

## 5. 自评

1. **回抽器已知偏差**：词法覆盖阈值 0.5 对**两词事实**偏宽松，位置/限定词漏配会误判命中（例："no suprapubic pain" 因 `suprapubic` 未匹配、仅 `pain` 命中 1/2 即判 True）。数字 2↔two 已做归一，但仍有边界。回抽一致率 ~95%，属于可接受的观测噪声，且 A/B 两侧对称、对 A−B 差影响有限。
2. **判等规则边界**：LLM 判等对**病因/亚型修饰词偏宽容**（"orthostatic hypotension due to metoprolol" 判等于 "orthostatic hypotension"、"new-onset type 1 DM" 判等于 "diabetes mellitus"）。绝对准确率 0.524 可能因此高估 2–3pp，但不影响 Δ（Δ 完全归零、两侧对称）。
3. **开放式诊断 prompt 暗示**：prompt 仅含主诉 + 对话记录，无疾病名/器官名/科室名，符合禁止项；主诉本身含症状描述（原始数据，不可避免）。只跑一版，未调参重试。
