## 0. 一句话

把这套东西做成 **医学 LLM 交互式诊断的「问诊质量」评测**：医生模型自由发问，患者由一台按真实分布校准的模拟器承担，最终交付一个能对「怎么问」打分并归因的场景。

不是模拟器论文，不是训练方法论文，是评测论文。

## 2. 北极星与里程碑

**北极星**：一篇能站住的评测论文。判据不是「做完了」，而是「有人能拿着我们的 harness 复现出模型排序，并承认这个排序测到了别的东西测不到的能力」。

| 里程碑 | 内容 | 状态 | 验收条件（可证伪） |
|---|---|---|---|
| **M0** | 真实语料效应量测量 | ✅ 2026-11-26 | 5 个假设在 MTS-Dialog 全量上有方向与显著性；一致性 AC1 ≥ 0.7 |
| **M1** | **阶段共线排查** | ✅ 2026-11-26 | 控制 `turn_index` + `stage` 后四条假设系数变化 1.0%–23.0%，均 < 50%。V ≤ 0.16，无强共线。**R1 排除** |
| **M2** | 校准模拟器（可迁移性验证） | ⬜ 待启动（当前最高优先） | 见 §2.1 七条判据；**不是「模拟器像不像人」，是「措辞效应能否从真人迁移到 LLM 患者」** |
| **M3** | 自由问诊 harness | ⬜ | 去掉策略注入后，5 个模型 × 50 病例跑通，产出措辞分布表且 test-retest 排序一致 |
| **M4** | Benchmark + 效度论证 | ⬜ | 三个模型在「提问质量」与「诊断准确率」上的排序**不一致**（否则新指标无增量）；人类基线可复现 |
| **M5** | 关系层维度（R1 共情） | ⬜ 备选 | 加 R1 后，敏感话题（性史/用药/心理）的披露率出现可测变化；且与 L1 维度无共线（|r| < 0.3） |

**M1 结论（已归档）**：四条假设在控制时机后系数变化 1.0%–23.0%，全部通过。**H5（开放→溢出）控制后系数反而变大（+0.528 → +0.649），说明时机此前在压制效应，M2 参数表必须用控后值 0.649，不得用 0.528。**

**M1 的两处遗留，并入 M2a 一并处理**：

1. GEE 系数混合了 within/between 变异，未做对话内固定效应。补 `C(dialogue_id)` 重估一遍。
2. **反常发现**：Cramér's V 仅 0.075–0.160，说明语料里「开场并不更开放」，与 Calgary-Cambridge 的漏斗结构矛盾。opening 阶段有 2025 条而 open 总数仅 742，**高度怀疑标注口径把「你哪里不舒服」判成了 semi**。M2a 必须核查 opening 阶段的 open/semi/closed 分布。

## 2.1 M2 详解：它到底要证明什么

### 定位（写论文时照这个口径，不要写成工程验收）

> **证明「措辞 → 披露」的效应可以从真医患对话迁移到 LLM 扮演的患者。**

不是「验证我们的模拟器做得好」。是**可迁移性（transportability）** 的证明。区别在于：

- 写成「模拟器像人」→ 读者认为是模拟器论文，直接撞 PWP（2606.17441）
- 写成「效应可迁移」→ 读者认为是一条可迁移的规律，顺带回答了「为什么过去的模拟器都测不出提问质量」

### 为什么这一步不可省

| 步 | 数据 | 能得到 | 不能得到 |
|---|---|---|---|
| M1 | 真实对话 | 措辞与披露的**关联** | 因果（无法要求真实医生随机分配措辞） |
| **M2** | 真实对话 + 模拟器 | **关联可迁移到可干预的环境** | — |
| M3 | 只用模拟器 | **干预**：同患者、只改问法、看结局分叉 | — |

因果干预只能在假环境里做，而假环境凭什么代表真的——M2 就是这句质问的答案。

### M2 要杀掉的三种失效模式

| # | 失效 | 表现 | 靠哪条判据杀 |
|---|---|---|---|
| F1 | 措辞不敏感 | 一律多说，M3 里所有医生同分 | B2、C1 |
| F2 | 照 prompt 演 | marginal 与反事实都能对上，但没有「估计」这一步 | **B1–B4（只有结构判据能杀）** |
| F3 | 系统偏差 | 如强引导附和 80%（真人 51.6%），造出假排名 | A1、A2 + 用人类盲标子集复核 |

**F2 是当前 `phaseA` 的病，也是最难杀的**——它读的是 prompt，不是 5325 条数据，所以边际分布和反事实改写都能通过。唯一能识别它的是「状态依赖」类判据。

### 四步拆分与工期

| 子任务 | 内容 | 工期 | 依赖 |
|---|---|---|---|
| **M2a 真值表** | 从患者回答抽 **AIU 文本**（不是计数）、跨轮去重、标保真度；核查 opening 阶段 openness 分布；补 `C(dialogue_id)` 固定效应 | 3 天 | 盲标结论（阶段 1） |
| **M2b 参数表** | 以 `(措辞 × 患者剩余状态 × 轮次)` 为条件估四组概率 + 每患者随机基线 | 2 天 | M2a |
| **M2c 两段式生成** | 统计层决定说什么（AIU 集、保真度、是否溢出），LLM 只负责怎么说，**硬约束不得增删 AIU** | 3 天 | M2b |
| **M2d 回放校准** | 留出 20% 对话，七条判据全测 | 2 天 | M2c |

**M2a 是硬前置**：现有标注里 `info_units` 只有**计数**，全库没有一条 AIU 的**文本内容**。模拟器必须知道「这个患者知道哪几件事」才能决定说哪几件。这不是整理工作，是重做一遍抽取。

### 七条判据（写死，跑完不得改）

留出 20% 对话（约 270 段 / 1370 条问答对），**从头到尾不参与参数估计**。

**A 组 · 边际一致（必要，不充分）**

| # | 判据 | 阈值 |
|---|---|---|
| A1 | 四个披露属性的模拟分布 vs 真实分布，绝对偏差 | 各 ≤ 3pp |
| A2 | bootstrap 95% CI | 与真实 CI 重叠 |

**B 组 · 结构一致（杀掉 F2，这组是重点）**

| # | 判据 | 阈值 | F2 为什么过不了 |
|---|---|---|---|
| B1 | 患者间异质性：患者间披露量方差 / 真人方差 | ≥ 0.8 | 照演的模拟器对所有患者一视同仁，方差趋零 |
| B2 | 残量效应：按 `turn_index` 分层的披露量斜率，与真人斜率之差 | ≤ 30% | 照演的不「累」，斜率是平的 |
| B3 | 历史依赖：相邻轮披露量自相关 | ≥ 0.15 | 照演的每轮独立，自相关为 0 |
| B4 | 内容正确性：模拟输出抽回 AIU 后，命中真值集比例 ≥ 90%，且**不得出现真值集外的 AIU** | 硬性 | 照演的根本不知道真值集 |

**C 组 · 反事实（防「只学到相关、没学到因果」）**

| # | 判据 | 阈值 |
|---|---|---|
| C1 | 留出集医生 open 问句改写为 closed（内容不变），spillover 率下降幅度 | 落在真人估计的 95% CI 内 |
| C2 | 该改写后 AIU 命中率不变（证明只改形式未改内容） | 变化 ≤ 2pp |

### 判定规则

| 组合 | 判定 | 处置 |
|---|---|---|
| A 全过 + B ≥ 3/4 + C 全过 | ✅ 通过 | M3 开工 |
| A 全过 + B ≤ 2/4 | ❌ **照演型模拟器** | 回 M2b 加状态依赖，禁止调阈值 |
| A 全过 + B ≥ 3/4 + C 不过 | ⚠️ 只学到相关 | M3 可测披露量，**不得**宣称测引导性与复合性 |
| A 部分过 | ⚠️ 降级 | 只报通过的属性，标题降为「信息提取效率」，不得说测「问得好不好」 |
| A 全不过 | ❌ 失败 | 故事退回 M1，写成纯语料实证研究（见 R4） |

### 禁止项

1. 禁止在 prompt 里写任何「开放式多说 / 封闭式简短」类规则（D1）。
2. 禁止用参与参数估计的对话做校准（必须留出）。
3. 禁止在判据不过时下调阈值。要改阈值，走主控批准 + 变更记录。
4. 禁止把「人工看着像」当作通过依据（D6）。

### 人类盲标：两阶段，先花 2 小时决策

| 阶段 | 条数 | 谁标 | 决策 |
|---|---|---|---|
| **阶段 1（先做）** | 60 | 你 + 1 名未参与 rubric 设计者，重叠 20 条 | AC1 ≥ 0.8 → 停，后续直接用 qwen 标注；0.6–0.8 → 扩到 200；**< 0.6 → 停 M2，先修 rubric** |
| 阶段 2（若需要） | 200（含阶段 1 的 60） | 同上 | 只标 `leadingness` 与 `openness` 两个维度，盲标（看不到 qwen 标签、看不到 rubric 示例答案） |

**抽样必须分层，不能随机**：稀有档位强制纳入——`strong` leading 全库仅 188 条，抽 40；`multi_barreled` 264 条，抽 40；`surface` follow_up 311 条，抽 40。随机抽 200 条很可能一条 strong 都没有，那就白标了。

**用途**：① 人 vs qwen 一致性，决定 M1 结论是否成立；② 这 200 条作为 M2d 校准验收的参照标准，而非对照 qwen。

## 3. 十条纪律

违反任一条，该次交付作废，重做。

**D1 不许用 prompt 指令充当机制。**
患者「多说」必须来自采样参数或条件概率表，不许来自 system prompt 里的角色说明。
> 现状违反：`src/patient.py` 第 26–27 行直接写「开放式就展开补充，封闭式就简短」。这是循环论证，只能当管线自检，不能进任何结果。

**D2 跨轮统计必须控制对话阶段。**
所有「措辞 → 披露」模型必须含 `turn_index`（或 stage 分层），并同时报告控制前/控制后两组系数。只报控制前，视为无效。

**D3 独立性以对话为单位。**
同一对话内的多条问答对不独立。样本量报 `n_dialogue`，不报 `n_pair`；p 值必须来自聚类稳健 SE 或混合模型。
> 现状违反：`scripts/analyze.py` 用 289 个配对做 t 检验，同一病例内 6 个信息点被当成独立样本，p 值会严重虚高。

**D4 效应量优先于 p 值。**
任何结论 = 效应量 + 95% CI + n。只有 p 值没有效应量的结果，不进正文。

**D5 结论必须标证据等级。**
E1 真实语料观察 / E2 模拟器回放匹配 / E3 端到端干预 / E4 人类基线。不得把 E2 写成 E1，不得把 E3（我们注入了策略）写成「模型自己会这么问」。

**D6 模拟器校准只认结构一致性，不认「像不像」，也不只认边际分布。**
人工「像不像」评分可作辅助，不能作主证据。**但边际分布匹配同样不够**——prompt 里写死「开放式说 2–3 件」的模拟器，用真实问句序列回放也能对上边际分布与反事实（即 F2 失效模式）。主证据必须是 §2.1 的 B 组四条结构判据：患者间异质性、残量效应、历史依赖、内容正确性。这四条共同要求「参数是从数据估出来的」，而不是从 prompt 读出来的。

**D7 真值隔离。**
医生 agent 任何时候不得读 `diagnosis` 字段；评测代码与 agent 代码物理分离（不同目录，评测侧只 import 结果，不 import agent 内部状态）。

**D8 可复现。**
固定 seed、模型快照版本号、prompt 全文快照；输出落到 `outputs/<YYYYMMDD>_<name>/`，含 `config.json` 与 `run.log`。缺任一项不算交付。

**D9 数据只追加。**
`data/` 下已发布文件不改。新版本另起文件名带日期（`mtsdialog_parsed_20261126.json`），旧版保留。

**D10 失败要留档。**
被推翻的假设、跑不通的方案，写进 `docs/negatives.md`，不许静默删除。负面结果是对外可信度的一部分。

## 4. 工作流

```
提案（写清问题/假设/验收条件）
   ↓ 主控批准：只批有可证伪验收条件的提案
执行侧实现 + 跑
   ↓ 交付物四件套：代码 / 一行可跑命令 / 输出文件 / 自评（含「没测到什么」）
主控验收：只对验收条件，不看代码风格
   ↓ 通过 → 合并 + 更新 STATUS；不通过 → 退回，写清缺哪条
```

**交付物四件套**，缺一不算交付：

1. 代码（能跑）
2. 一行可复现命令（我要能原样粘贴执行）
3. 输出文件（原始结果，不是截图）
4. 自评 200 字：**这条实验测到了什么、没测到什么、哪一步可能出错**

第 4 项最重要。执行侧写不出「没测到什么」，说明它没想清楚在测什么。

## 5. 现状盘点（2026-11-26）

### 已经成立

- **真实语料效应量表**：MTS-Dialog 1501 段 / 5325 问答对，5 个假设全部方向正确且显著，AC1 ≥ 0.77
- **阶段共线已排除（M1）**：控制 `turn_index` + `stage` 后系数变化 1.0%–23.0%，V ≤ 0.16。措辞效应不是「时机效应」的伪装
- 四维提问 × 四属性披露的标注 rubric 已定稿并通过一致性门槛
- 阶段 A 管线（DDxPlus 50 例）能跑通 —— 但结论是循环论证，只作管线自检

### 关于维度的两个判断（2026-11-26 修正）

1. **现有四维（openness / leadingness / multi_barreled / follow_up）全部落在形式层与语用层，关系层一维未做。** 前者测「信息怎么被取出」，后者测「患者愿不愿意给」。敏感信息（性史、用药、心理、家暴）几乎不因问句形式而出现，却会因共情与正常化而出现——这是最大的空白，也是与现有工作拉开距离最干净的地方。
2. **H1（开放度 → 披露量）是同义反复，不能当主结论。** 是非问只能答「是」，必然短。项目重量应压在 H2（引导 → 附和）与 H3（复合 → 漏答）上，因为这两条说的是信息被污染、被丢失，不是信息变少。

### 假设编号（v2 起唯一有效，旧编号一律作废）

| 编号 | 假设 | 角色 | M1 控后 β | 变化 |
|---|---|---|---|---|
| H1 | 开放度 → 披露量 | **操纵检查**，不进正文结论 | — | — |
| H2 | 引导性 → 附和 | **核心** | +0.982 | 2.9% |
| H3 | 复合性 → 漏答 | **核心** | +1.214 | 9.9% |
| H4 | 追问深度 → 精确 | 支撑 | +0.685 | 1.0% |
| H5 | 开放度 → 溢出 | **核心** | **+0.649** | 23.0% |

> `docs/step1_results_full.md` 用的是旧编号（H2=开放→溢出、H3=引导→附和、H4=复合→漏答、H5=追问→精确）。两者错位，引用时以本表为准。**H5 参数一律用控后值 0.649。**
