# 项目章程

> 版本 v1 · 2026-11-26 · 由主控维护，改动需记入文末变更记录

---

## 0. 一句话

把这套东西做成 **医学 LLM 交互式诊断的「问诊质量」评测**：医生模型自由发问，患者由一台按真实分布校准的模拟器承担，最终交付一个能对「怎么问」打分并归因的场景。

不是模拟器论文，不是训练方法论文，是评测论文。

---

## 1. 角色与决策边界

| 角色 | 负责 | 不负责 |
|---|---|---|
| **主控**（我） | 方向、优先级、验收、跨任务一致性、对外表述口径 | 不写实现代码、不调参、不跑实验 |
| **执行侧 agent** | 实现、跑实验、出图表、写可复现命令 | 不改研究方向、不改验收判据、不自行宣布结论 |

**必须回到主控的四件事**（执行侧不得自行决定）：

1. 更换数据集或语料
2. 修改研究问题、假设、指标定义
3. 得出一个要写进论文的结论
4. 偏离已批准的验收条件

**执行侧可自主决定**：代码结构、库选择、并发策略、日志格式、单测写法。

## 2. 北极星与里程碑

**北极星**：一篇能站住的评测论文。判据不是「做完了」，而是「有人能拿着我们的 harness 复现出模型排序，并承认这个排序测到了别的东西测不到的能力」。

| 里程碑 | 内容 | 状态 | 验收条件（可证伪） |
|---|---|---|---|
| **M0** | 真实语料效应量测量 | ✅ 完成 2026-11 | 5 个假设在 MTS-Dialog 全量上有方向与显著性；一致性 AC1 ≥ 0.7 |
| **M1** | **阶段共线排查** | 🔴 进行中（最高优先） | 混合模型加入 `turn_index` + `stage` 后，H2/H3/H4 的系数变化 < 50%；若 > 50%，需重写研究问题 |
| **M2** | 校准模拟器 | ⬜ 待启动 | 回放检验通过：200 段真实问句序列驱动模拟器，溢出率/附和率/漏答率与真实患者差 ≤ 3pp，bootstrap 95% CI 重叠 |
| **M3** | 自由问诊 harness | ⬜ | 去掉策略注入后，5 个模型 × 50 病例跑通，产出措辞分布表且 test-retest 排序一致 |
| **M4** | Benchmark + 效度论证 | ⬜ | 三个模型在「提问质量」与「诊断准确率」上的排序**不一致**（否则新指标无增量）；人类基线可复现 |
| **M5** | 关系层维度（R1 共情） | ⬜ 备选 | 加 R1 后，敏感话题（性史/用药/心理）的披露率出现可测变化；且与 L1 维度无共线（|r| < 0.3） |

**为什么 M1 在前**：如果效应主要来自「开场问得开放 + 开场患者说得多」，后面所有工程都建在沙上。这一项一周内能做完，却决定项目生死。**在 M1 通过前，M2 不开工。**

## 3. 十条纪律

违反任一条，该次交付作废，重做。

**D1 不许用 prompt 指令充当机制。**
患者「多说」必须来自采样参数或条件概率表，不许来自 system prompt 里的角色说明。
> 现状违反：`src/patient.py` 第 26–27 行直接写「开放式就展开补充，封闭式就简短」。这是循环论证，只能当管线自检，不能进任何结果。

**D2 跨轮统计必须控制对话阶段。**
所有「措辞 → 披露」模型必须含 `turn_index`（或 stage 分层），并同时报告控制前/控制后两组系数。只报控制前，视为无效。

**D3 独立性以对话为单位。**
同一对话内的多条问答对不独立。样本量报 `n_dialogue`，不报 `n_pair`；p 值必须来自聚类稳健 SE 或混合模型。
> 现状违反：`scripts/analyze.py` 用 289 个配对做 t 检验，同一病例内 6 个信息点被当成独立样本，p 值会严重虚高。

**D4 效应量优先于 p 值。**
任何结论 = 效应量 + 95% CI + n。只有 p 值没有效应量的结果，不进正文。

**D5 结论必须标证据等级。**
E1 真实语料观察 / E2 模拟器回放匹配 / E3 端到端干预 / E4 人类基线。不得把 E2 写成 E1，不得把 E3（我们注入了策略）写成「模型自己会这么问」。

**D6 模拟器校准只认分布匹配。**
人工「像不像」评分可作辅助，不能作主证据。主证据是：给定同一串真实问句，模拟器与真实患者的披露分布是否同分布（KS / 卡方 / CI 重叠）。

**D7 真值隔离。**
医生 agent 任何时候不得读 `diagnosis` 字段；评测代码与 agent 代码物理分离（不同目录，评测侧只 import 结果，不 import agent 内部状态）。

**D8 可复现。**
固定 seed、模型快照版本号、prompt 全文快照；输出落到 `outputs/<YYYYMMDD>_<name>/`，含 `config.json` 与 `run.log`。缺任一项不算交付。

**D9 数据只追加。**
`data/` 下已发布文件不改。新版本另起文件名带日期（`mtsdialog_parsed_20261126.json`），旧版保留。

**D10 失败要留档。**
被推翻的假设、跑不通的方案，写进 `docs/negatives.md`，不许静默删除。负面结果是对外可信度的一部分。

## 4. 工作流

```
提案（写清问题/假设/验收条件）
   ↓ 主控批准：只批有可证伪验收条件的提案
执行侧实现 + 跑
   ↓ 交付物四件套：代码 / 一行可跑命令 / 输出文件 / 自评（含「没测到什么」）
主控验收：只对验收条件，不看代码风格
   ↓ 通过 → 合并 + 更新 STATUS；不通过 → 退回，写清缺哪条
```

**交付物四件套**，缺一不算交付：

1. 代码（能跑）
2. 一行可复现命令（我要能原样粘贴执行）
3. 输出文件（原始结果，不是截图）
4. 自评 200 字：**这条实验测到了什么、没测到什么、哪一步可能出错**

第 4 项最重要。执行侧写不出「没测到什么」，说明它没想清楚在测什么。

## 5. 现状盘点（2026-11-26）

### 已经成立

- **真实语料效应量表**：MTS-Dialog 1501 段 / 5325 问答对，5 个假设全部方向正确且显著，AC1 ≥ 0.77
- 四维提问 × 四属性披露的标注 rubric 已定稿并通过一致性门槛
- 阶段 A 管线（DDxPlus 50 例）能跑通 —— 但结论是循环论证，只作管线自检

### 关于维度的两个判断（2026-11-26 修正）

1. **现有四维（openness / leadingness / multi_barreled / follow_up）全部落在形式层与语用层，关系层一维未做。** 前者测「信息怎么被取出」，后者测「患者愿不愿意给」。敏感信息（性史、用药、心理、家暴）几乎不因问句形式而出现，却会因共情与正常化而出现——这是最大的空白，也是与现有工作拉开距离最干净的地方。
2. **H1（开放度 → 披露量）是同义反复，不能当主结论。** 是非问只能答「是」，必然短。项目重量应压在 H2（引导 → 附和）与 H3（复合 → 漏答）上，因为这两条说的是信息被污染、被丢失，不是信息变少。

### 明确缺少

| 缺什么 | 影响 | 对应 |
|---|---|---|
| 阶段控制 | 效应可能全是「开场效应」 | M1 |
| 校准模拟器 | 现在的患者是 prompt 硬编码，不是测出来的 | M2 |
| 自由问诊模式 | 现在只有「强制开放/强制封闭」两组，属干预实验 | M3 |
| 人类基线 | 没有基线，分数无意义 | M4 |
| 意图标签 | AIU 只有文本，没有「是否诊断必要」的标注 | M4 |

### 代码债务（已知，不必再查）

| 位置 | 问题 | 处置 |
|---|---|---|
| `src/patient.py` L26–27 | prompt 直接规定「开放式就多说」 | M2 用条件概率表替换 |
| `src/metrics.py` | 提取器与患者同为 qwen-flash，同源 | 换第三方模型抽取，报一致性 |
| `scripts/analyze.py` | 配对 t 检验忽略病例内相关 | 废弃，统一用 `analyze_effects.py` |
| `src/doctor.py` | 策略注入 = 干预，不是测量 | M3 拆成 `doctor_free.py` |
| `src/cases.py` | 硬编码 2 个中文样例，与实际数据脱节 | 删除或移到 `examples/` |

## 6. 风险登记

| # | 风险 | 概率 | 影响 | 处置 |
|---|---|---|---|---|
| R1 | 效应主要来自对话阶段，控制后消失 | 中 | 致命 | M1 先行 |
| R2 | 标注同源（flash/plus 都是 qwen） | 高 | 中 | 人工盲标 200 条 |
| R3 | 提取器与患者同源，测量被污染 | 高 | 中 | 换模型 + 报抽取一致性 |
| R4 | 效应在 LLM 患者上不复现（真人有，模型没有） | 中 | 高 | M2 回放检验正是检验这个；若不复现，改为「模拟器偏差研究」，故事仍成立但结论要改 |
| R5 | 新指标与诊断准确率排序一致，无增量 | 中 | 高 | M4 验收条件直接测这个 |

R4 值得单独说：如果 LLM 患者**不**因措辞改变披露，那不是失败，而是一个更有意思的发现——"模拟器的措辞不敏感"本身就是当前评测失效的证据。但论文口径必须改，不能硬说我们复现了真人效应。
