- `*` 标注的低 κ 是 **κ 悖论**（类别极度不平衡，如 neutral 占 90%、single 占 95%、on-topic 占 91%），并非 rubric 差。用对不平衡稳健的 **Gwet's AC1** 评估，8 维全部 ≥ 0.77，通过。
- `info_units`（连续）：Pearson r=0.84，MAE=0.39，flash/plus 均值 1.51/1.74，量级一致。
- **openness 从初版 κ=0.49 → 0.914**、**definiteness 从 0.50 → 0.81**：rubric 修改是有效且必要的。

## 200 条小样的初步效应量信号（方向验证）

| 假设 | 结果 | 显著性 |
|---|---|---|
| 开放度 ↑ → 披露量 ↑ | info_units: closed 1.17 → semi 1.91 → open 2.12（d=-0.94）；词数 6.88→12.62→15.03 | p=3.9e-08 |
| 开放度 ↑ → spillover ↑ | 5.1% → 12.8% → 18.2% | p=0.036 |
| 引导性 ↑ → 附和(agree) ↑ | neutral 17.6% → mild 14.3% → **strong 71.4%** | p=0.0026 |
| 复合性 ↑ → 漏答 ↑ | single 3.1% vs multi 0.0% | 不显著（multi 仅 7 条，待全量） |
| 追问深度 → 更 exact | surface 7.7% → new 71.8% → **deepen 75.2%** | p=4.6e-06 |
| spillover ⇒ 更多披露 | on-topic 1.37 vs spillover 2.83 info_units | p=1.5e-09 |

**结论**：5 个假设中 4 个方向正确且显著，复合性待全量样本。核心假设「开放式提问 → 患者自发溢出更多信息」在真实对话上初步成立。
